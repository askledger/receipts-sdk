Embeddable verifier widget

Drop one custom element on any page. 8 KB. Zero deps. Verified inline.

Live

Install

<script src="https://askledger.github.io/receipts-sdk/verify.html/widget.js"></script>
<pl-verifier receipt-id="01J9X8VK0001"></pl-verifier>

Attributes

  • receipt-id — required. UUIDv7-shaped id from a SignedReceipt.
  • endpoint — optional. Default https://askledger.github.io/receipts-sdk/verify.html.

Why publish receipt badges?

If your product uses AI to make a decision about a customer, a verifier badge gives the customer the ability to confirm independently that the decision was recorded, signed, and chain-witnessed.
